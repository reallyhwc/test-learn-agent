# 失败模式手册（Troubleshooting Playbook）

本目录沉淀了项目运行中**反复出现的失败场景**及其排查路径。
新人遇到问题时**先查这里**，再问人或调试。

| 编号 | 场景 | 何时查阅 |

## 写新条目

格式：
1. **症状**（用户/日志看到的现象）
2. **常见原因**（按概率从高到低）
3. **排查步骤**（具体命令/文件路径）
4. **根因修复**
5. **关联代码** （文件 + 行号）

每个 .md 命名：`NN-简述.md`，NN 递增。

## 维护规则

- 新人遇到一次新坑 → 写一篇
- 同一坑被踩第三次 → 检查是不是这里的文档不够清晰，更新它
- 旧文档 case 已经被代码层面消除（如修了 bug） → 加 `> [已修复 @YYYY-MM-DD] 保留作为历史参考`，不删除
