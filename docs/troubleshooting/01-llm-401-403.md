# 01 — LLM API 调用 401 / 403

## 症状

- 前端 chat 框输入消息后，长时间无响应或直接报错
- Agent 日志（`logs/agent-java.log` 或 `logs/agent-python.log`）出现：
  - `401 Unauthorized` / `Invalid API key`
  - `403 Forbidden` / `Permission denied`
  - `OpenAI API error: ...`

## 常见原因（按概率排序）

### 1. `.env` 文件缺失或 `LLM_API_KEY` 为空 (60%)

```bash
# 验证
cat .env | grep LLM_API_KEY
# 如果输出 LLM_API_KEY= 后没东西，或没有这一行 → 中招
```

**修复**：
```bash
cp .env.example .env
# 编辑 .env 填入 LLM_API_KEY
```

### 2. `LLM_BASE_URL` 配错（含或缺 `/v1`） (25%)

不同提供商的 base URL 拼接规则不一样：

| 提供商 | 正确 LLM_BASE_URL |
|--------|-------------------|
| DeepSeek | `https://api.deepseek.com` |
| OpenAI | `https://api.openai.com` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| Moonshot | `https://api.moonshot.cn/v1` |
| **idealab DogFooding** | `https://idealab.alibaba-inc.com/api/openai`（**不带 /v1**） |
| Groq | `https://api.groq.com/openai/v1` |
| SiliconFlow | `https://api.siliconflow.cn/v1` |

**为什么 DeepSeek 和 idealab 不带 `/v1`？**
Spring AI 的 OpenAI client 会自动拼 `/v1/chat/completions`，对于 DeepSeek 用裸根域名即可；idealab 的特殊路径是 `/api/openai/v1/chat/completions`，所以 base 写 `/api/openai`。

### 3. API Key 已过期或额度耗尽 (10%)

```bash
# 用 curl 直接验证，绕过 Agent
curl -sS "${LLM_BASE_URL}/v1/models" \
  -H "Authorization: Bearer ${LLM_API_KEY}" | head -20
```

返回 401 → key 失效；返回模型列表 → key 没问题。

### 4. 模型名错误 (5%)

不同提供商的 `LLM_MODEL` 取值：
- DeepSeek: `deepseek-chat` / `deepseek-reasoner`
- OpenAI: `gpt-4o-mini` / `gpt-4o`
- 通义千问: `qwen-plus` / `qwen-max`
- idealab: `gpt-4o-2024-11-20` / `claude-3-7-sonnet-20250219`（具体见 idealab 控制台）

## 排查步骤

```bash
# 1. 确认 .env 内容
grep -E "LLM_(API_KEY|BASE_URL|MODEL)" .env

# 2. 确认 Agent 真的读到了这些变量（用 restart 子命令的日志）
./start-all.sh restart-java-agent
tail -50 logs/agent-java.log | grep -E "spring.ai.openai|api-key|base-url"

# 3. 用 curl 直接验证 LLM 端点
source .env
curl -sS -X POST "${LLM_BASE_URL}/v1/chat/completions" \
  -H "Authorization: Bearer ${LLM_API_KEY}" \
  -H "Content-Type: application/json" \
  -d "{\"model\":\"${LLM_MODEL}\",\"messages\":[{\"role\":\"user\",\"content\":\"hi\"}]}" | head
```
